## Mad GOTTA 🧸

A custom Go web stack for building modern web applications with 
Gin, templ, HTMX, Tailwind CSS, and Alpine.js.

## Tech Stack
 - 🐹 Go
 - ⚡ Backend: Gin
 - 🧩 Templates: templ
 - 🔄 Interactions: HTMX
 - 🎨 Styling: Tailwind CSS
 - 🤏 Frontend: Alpine.js
 - 🗃️ Database: SQLite
 - 🧪 Testing: Go Testing
